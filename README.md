# Politique de confidentialité - PloufPlouf
*Dernière mise à jour : mai 2026*

 **1. Données collectées :** PloufPlouf collecte les données suivantes :
 

 - Adresse email (pour la création de compte)
 - Nom d'utilisateur et mot de passe (choisis par l'utilisateur)
 - Contenu de la bucket list et de l'agenda (items, événements, likes)

**2. Utilisation des données:** Ces données sont utilisées uniquement pour :

 - Permettre la connexion et l'identification
 - Synchroniser la bucket list entre les membres d'un groupe
 - Afficher les notifications d'événements

**3. Stockage:** Les données sont stockées de manière sécurisée via Supabase (supabase.com), hébergé sur des serverus en Europe. 

**4. Partage des données:** Aucune donnée n'est vendue ou partagée avec des tiers à des fins publicitaires.
